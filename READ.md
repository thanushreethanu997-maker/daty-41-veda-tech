Personal Expense & Budget Tracker

Project Description

A Python-based application that helps users record daily expenses, manage monthly budgets, organize spending into categories, and generate spending summaries.

Features

- Add daily expenses
- View all expenses
- Edit existing expenses
- Delete expenses
- Category-wise expense management
- Set monthly budgets
- Generate daily and monthly spending summaries
- Search and filter expenses
- Store data using CSV and JSON files
- Validate amount, date, and category

Technologies Used

- Python
- CSV
- JSON
- Datetime
- VS Code
- Git
- GitHub

How to Run

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Run the application:

python main.py

4. Select an option from the menu.
